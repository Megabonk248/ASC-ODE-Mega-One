## 1. Double Pendulum with Springs

We begin with a double pendulum connected by springs, which serves as a simple and intuitive example of the mass–spring system. The pendulum consists of two masses connected by springs and influenced by gravity, allowing us to observe oscillatory motion and energy exchange between the components.

## 3. Double Pendulum with Distance Constraints

In addition to the spring-based models, we implemented a double pendulum using distance constraints instead of springs. In this setup, the distance between connected points is kept constant, resulting in a more rigid and physically accurate pendulum motion.

This example demonstrates how constraints can be used to control the system behavior directly, and it serves as a comparison to the spring-based approach shown in the previous examples.
